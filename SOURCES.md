## Interaction references for future production hardening
The current prototype keeps its core editor dependency-light, but these mature open-source projects are useful references or drop-in upgrades:

- PhotoSwipe — zoom/lightbox: https://github.com/dimsemenov/PhotoSwipe
- VanillaTilt — 3D tilt: https://github.com/micku7zu/vanilla-tilt.js
- Lenis — smooth scrolling: https://github.com/darkroomengineering/lenis
- Motion — richer animation primitives: https://github.com/motiondivision/motion

The visual systems and editor UI in this repository are custom for this portfolio rather than copied from a portfolio template.

The second "Gallery Rail" direction was retired; the repository now holds one portfolio site.
